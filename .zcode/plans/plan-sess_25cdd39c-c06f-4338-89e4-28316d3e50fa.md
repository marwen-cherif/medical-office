## Plan — UX notification rappel : nom patient cliquable + icône WhatsApp

### Contexte
Le « message de notification du rappel » est le popover `RappelsBell.tsx`. Aujourd'hui il affiche `Patient #<id>` en texte statique et un bouton « Envoyer WhatsApp » avec l'icône générique `MessageSquare`. Blocage : le type `Rappel` ne porte que `patient_id`, pas le nom → il faut d'abord enrichir le backend.

### 1. Backend — enrichir la liste des rappels avec le nom patient

**`apps/api/crm/repo.py`** — `list_rappels()` (ligne ~3554) :
- Ajouter un `LEFT JOIN patients pt ON pt.id = r.patient_id` (LEFT car patient_id peut être null)
- Retourner `list[tuple[Rappel, str | None]]` où le 2e élément = display name (`f"{nom.upper()} {prenom}"`)
- Signature : `list_rappels(...) -> list[tuple[Rappel, str | None]]`
- Garder `count_rappels` inchangé (pas besoin du nom pour le comptage)

**`apps/api/crm/routers/rappels.py`** :
- Ajouter `patient_display: Optional[str] = None` à `RappelOut`
- Étendre `_rappel_out()` pour accepter un `patient_display` optionnel
- `rappels_list` : utiliser la nouvelle signature tuple et passer le display

### 2. Frontend — types

**`apps/web/src/api/types.ts`** — type `Rappel` : ajouter `patient_display?: string | null`

### 3. Frontend — cloche `RappelsBell.tsx`

- Ligne `Échéance : ... · Patient #<id>` → la remplacer : quand `r.patient_display` existe, l'afficher comme **lien cliquable** (`hover:underline text-navy`) → `navigate(\`/patients/${r.patient_id}\`)` + fermer le popover. Sinon afficher juste l'échéance.
- Retirer le bouton séparé « Fiche patient » (désormais redondant avec la ligne patient cliquable)
- Bouton « Envoyer WhatsApp » → **bouton icône compact** (`size="icon"` ou petit carré) avec le vrai glyphe `WhatsAppIcon` (import depuis `@/components/icons/WhatsAppIcon`), couleur emerald, au lieu du bouton large avec `MessageSquare` + texte. Tooltip au survol.

### 4. Frontend — tableau `Rappels.tsx`

- Colonne « Patient » : `#${r.patient_id}` → `<Link to={\`/patients/${r.patient_id}\`}>{r.patient_display ?? '#' + r.patient_id}</Link>` avec style lien (pattern idiomatique déjà utilisé dans Finances.tsx / Travaux.tsx)
- Bouton « Envoyer » : remplacer l'icône `MessageSquare` par `WhatsAppIcon` pour cohérence visuelle (garder le label « Envoyer » puisqu'il y a de la place dans le tableau)

### 5. Validation
- `tsc --noEmit` côté web
- Test rapide backend (les tests rappels existants si présents)
