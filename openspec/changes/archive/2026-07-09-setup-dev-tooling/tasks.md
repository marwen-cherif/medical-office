## 1. Outils Frontend (Vite/React)

- [x] 1.1 Installer les dépendances ESLint et Prettier pour React/TypeScript dans le projet `ui`.
- [x] 1.2 Créer le fichier de configuration `ui/eslint.config.js` pour ESLint v9 Flat Config.
- [x] 1.3 Créer le fichier de configuration `ui/.prettierrc` pour Prettier.
- [x] 1.4 Ajouter les scripts npm de linting et formatage dans le fichier `ui/package.json`.
- [x] 1.5 Installer les dépendances Vitest, jsdom, @testing-library/react et @testing-library/jest-dom dans le projet `ui`.
- [x] 1.6 Mettre à jour `ui/vite.config.ts` pour intégrer Vitest et ajouter les scripts de test dans `ui/package.json`.
- [x] 1.7 Écrire un test de composant d'exemple (`ui/src/lib/format.test.ts` ou test de bouton) pour tester et valider la configuration de Vitest avec Testing Library.
